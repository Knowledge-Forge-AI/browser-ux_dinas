# v0.0.1 public preview

This is the first public source preview of DINAS Browser UX.

The preview exposes policy-contribution modules, browser-role and extension
classification models, convenience-command sources, and the Browser UX Scrollbar
Visibility 0.4.0 source. It is intended for source review and development.

## Boundaries

- No installable extension package, binary release asset or registry package is
  published by this preview.
- Workstation integration depends on a compatible composition and its physical
  policy writers.
- Synthetic machine examples (`example-current-mac`, `example-previous-mac`) do
  not describe an operator's deployed state.
- The dormant Brave YouTube writer (`modules/brave-youtube-app-writer.sh`) covers
  only the current public bundle identity (`ai.knowledge-forge.dinas.brave-youtube`),
  the legacy Chrome Web App shortcut (`agimnkijcaahngcdmfeangaknmldooml`), and
  the `YouTube Brave` profile directory migration; pre-curation private app
  bundle cleanup is outside the public preview boundary.
- Package provenance checks enforce an exact direct build-context allowlist and
  runtime closure set equality for `packages.aarch64-darwin.browser-ux-commands`,
  supplemented by derivation name-token checks for recognizable public DINAS
  Core and browser derivation names (`google-chrome`, `chromium`); name checks
  do not claim arbitrary anonymous-flake-input detection.
- Public-source boundary checks (`public-source-boundary-contract`) validate
  `/Users/<seg>` and `/home/<seg>` path segments against an explicit synthetic
  allowlist, reject personal host-label patterns and unallowlisted GitHub owners,
  and forbid personal bundle prefixes and private worktree markers over a named
  set of source files (not every document or test); this is a bounded check, not
  complete personal-data detection.
- Source checks are separate from native installation, effective browser policy,
  credential compatibility and attended user-interface qualification.
- Experimental or held work remains identified as such; this preview does not
  claim completion of the broader Browser UX roadmap.
